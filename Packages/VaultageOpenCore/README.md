# Vaultage Open Core

This directory is generated by `product/scripts/export-open-core.mjs`. It is an independently buildable Swift library package containing the original VaultageCore domain/broker code, the generic VaultageMCP stdio contract, and the value-free VaultageBrokerContract wire shapes. Provider IDs and typed provider contracts in VaultageCore are public interfaces by design.

It is not a complete open-source desktop app. The native app shell, provider adapters/catalog, the service catalog and workspace projections, the XPC broker client and service, broker peer-identity constants, the hosted account/billing service, identity and billing integrations, website assets, signing, and packaging are outside this export.

## Build

From this directory, run `swift build`. The manifest has only the VaultageCore, VaultageMCP and VaultageBrokerContract targets and the external Swift MCP SDK dependency pinned by Package.resolved. No proprietary target or source is required.

To regenerate from the product workspace, run `node scripts/export-open-core.mjs` from `product`, then run `swift build` from `product/distribution/open-core`.
